# 🚀 v0 Interview Prep Assistant

An AI-powered interview preparation tool that helps users practice technical and behavioral interviews with real-time feedback and intelligent question generation.

🔗 **Repository:** https://github.com/21Umashankar/v0-interview-prep-assistant    
**Deploy Link:** https://v0-interview-prep-assistant-irxb-73nwtgx4g.vercel.app/


---

## 📌 Overview

The **v0 Interview Prep Assistant** is a smart web application designed to simulate real interview scenarios and help users improve their performance.

It acts as a **virtual interview coach**, allowing users to:
- Practice interview questions
- Improve communication skills
- Receive AI-based feedback
- Prepare efficiently for placements

---

## ✨ Features

- 🧠 **AI-Based Question Generation**  
  Generates technical and HR interview questions dynamically  

- 💬 **Interactive Chat Interface**  
  Practice in a conversational format  

- 📊 **Performance Feedback**  
  Improve answers with AI-driven suggestions  

- 🎯 **Multi-Domain Preparation**  
  Covers DSA, HR, and more  

- ⚡ **Fast & Clean UI**  
  Built with modern frontend tools for smooth experience  

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js (v0 UI)  
- **Backend:** Node.js / API Routes  
- **AI Integration:** OpenAI API  
- **Deployment:** Vercel / GitHub

## ⚙️ Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/21Umashankar/v0-interview-prep-assistant.git
cd v0-interview-prep-assistant
2. Install Dependencies
npm install
3. Configure Environment Variables

Create a .env.local file:

OPENAI_API_KEY=your_api_key_here
4. Run the Application
npm run dev
